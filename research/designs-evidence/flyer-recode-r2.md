Items: the 20 rows of `flyer-items.csv` (one 400 px preview each). Header and every other feature untouched.

## Method
- **Colour:** exactly as in brochure-recode-r2.md (B1a background = most common class on the 20x20 grid after dropping photo/illustration/text points; saturation never demotes it; B3 fill blocks by thick-area measurement, >= 10% = fill-blocks; B4-B6 for the rest). C44 scene rule applied: a full-page drawn scene is one illustration; a gradient background is one region (hues recorded, never counted); a photo counts as flat only if ΔL <= 0.10 (tint).
- **Admissibility (research/82 §5 A1-A8, C8, C46):** A3 only for running text, bullet text or a text block of >= 3 lines set directly on gradient/texture/photo; titles, subtitles, labels and captions of <= 2 lines on such a fill go to A6. A5 = >= 3 identical discrete motifs (not pattern bands, not differing icons). A6 by C9 sampling with `lib/color.contrast_ratio`: >= 4.5:1 below 24 pt, >= 3:1 at 24 pt or more, C29 literal thresholds. Thin strokes (< 2 px at 400 px) are sampled on the brightest/darkest core pixels (an upper bound for the true ratio) and flagged BORDERLINE (C50); they exclude only when that core ratio is below the threshold. All ratios are thumbnail estimates (C9).
