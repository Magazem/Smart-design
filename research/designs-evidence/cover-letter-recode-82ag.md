# research/designs-evidence/cover-letter-recode-82ag.md — header treatment & colour use recode under 82a-general (fresh recoder, 2026-09-24)

Scope: `header treatment` and `colour use` ONLY, for all 15 items in `cover-letter-items-l2.csv`,
per `research/82a-general.md` (superseding §4's rows for these two features) and 82a
clarifications 1-4. Admissibility and every other feature are untouched and not looked at.
Source material: `cover-letter-items-l2.csv` preview_url only. The letter/cover-letter corpus
.md files and any agreement file were NOT opened.

**Method.** Same scratch tooling and methodology note as `letter-recode-82ag.md` (same
`tmp-letrc/analyze.py`): `grid` (20x20 background sample, B1a), `inkcolors` (full/partial-page
scan for real chromatic ink, since the whole-page grid under-samples thin text/rules), `inkbox`/
ad hoc pixel bounding-box (element location and width%), `findbars`/`rowscan`/`colscan`
(full-width rule/band detection), `box` (median colour + dimensions of a region). All numeric
values below are copy-pasted from this script's output. Per A.1 for cover-letter: title = the
applicant's name; header block = name + role line + contact lines; boundary = as for letter
(date/recipient/salutation, whichever comes first).
