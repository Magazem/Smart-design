### report — GitHub corpus (research/designs-evidence/report-items-github.csv)

Recoder: fresh worker (has not coded report before; did not open `report-corpus*.md` or any
agreement file — item identity comes ONLY from `report-items-github.csv`, 40 rows). Scope:
`header treatment` and `colour use` only, per `research/82a-general.md` §A/§B, read with
`research/82a-clarifications-1..5.md`, especially **C13** (report/whitepaper/proposal code
header/colour from the **cover**; boundary = none, tests use the header block's own extent) and
**C1** (image-hero literal test: logos/crests never qualify). Where a row lists two preview URLs
separated by `;`, the **first** was used (the cover/title image, per C13 and the csv's own
ordering, e.g. GH:002's `..._1.png` before `..._2.png`). Single `.pdf` URLs were rendered at
**page 1** only.

**Method.** Previews fetched with `urllib` (browser UA) to
`research/designs-evidence/tmp-rprc/gh/` (scratch, deleted at the end of this task); `.pdf`
rendered page 1 via PyMuPDF (`fitz.Matrix(2,2)`), raster images converted directly; longest side
capped at 2200px. Pixel measurements taken with `analyze.py` (20×20 background-grid sampler,
region/point samplers) and `huescan.py` (stride-3 hue scan, S≥0.20 & 0.12≤L≤0.90, 10°-wide hue
bins with area-share) — both adapted line-for-line from `tmp-invrc/analyze.py`/`huescan.py`
(a different family's leftover scratch, read as a working reference). Rule/box-edge widths (the
recurring "title framed by two horizontal rules" LaTeX pattern) were measured exactly with a
row-scan script (counts dark pixels per row, reports the widest contiguous dark-pixel span as a
fraction of page width) rather than eyeballed — this repeatedly measured **71–79%** of page width
for that pattern (GH:032 73.9%, GH:043 71.3%, GH:067 76.4%, GH:077 78.9%, GH:094 66.7–67.4%),
consistently **under** the ≥80% ruled threshold, so all of those fall through to plain-centered;
the one exception is GH:086, where a *different*, wider bar (81.45%) sits directly above the
header block with a small gap, qualifying under the "full-width bar above the header block"
clause. Cap-heights for candidate "largest text" lines were compared with a row-band pixel-count
script where genuinely ambiguous (GH:073). Every hex/percentage below is script output, not
eyeballed. Almost every item in this corpus is a LaTeX academic title page (black text, one
university crest/wordmark, no other colour) — university crests, seals and calligraphy
wordmarks are excluded wholesale as logos (B1b) throughout, per the rule common to every family.
