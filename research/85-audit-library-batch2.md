# research/85 — Adversarial audit: grand-library batch 2 (ranked palettes + ratio type scales)

Auditor: Opus (adversarial). Date: 2026-09-23. Method: independent re-fetch with curl (no reuse
of the researcher's cached payloads), my own stdlib re-implementation of the pre-registered
filter and mapping, and `scripts/lib/color.py` (`contrast_ratio`, `relative_luminance`) for all
contrast. No git run. No file edited except this one. Tests were run with `-p no:cacheprovider`
and `PYTHONDONTWRITEBYTECODE=1`, so nothing was written.

Scope:
- A. `research/library/palettes/ranked-colourlovers.csv` (15 rows) + `-evidence.md` +
  `research/provenance/palettes-ranked-colourlovers.csv` (15 rows)
- B. `research/library/type-scales/ratio-families.csv` (45 rows, 9 scale_keys) + `-evidence.md` +
  `research/provenance/type-scales-ratio-families.csv` (45 rows)

Load state: all 15 palette rows, all 45 scale rows and all 60 provenance rows appear
byte-identical in `data/base/{palettes,type-scales,provenance}.csv`. The full suite
`pytest scripts/tests` reports **225 passed, 1 xfailed, 935 subtests passed**. The tests are
green, but they do not check the defects below: nothing tests Text-Safe roles against contrast,
and nothing tests evidence prose.
